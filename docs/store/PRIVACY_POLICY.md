**게임:** 핑 더 킬러 (Ping the Killer) — Windows용 멀티플레이어 게임

**문의:** [연락처 이메일]
**최종 수정일:** 2026-10-27

### 1. 요약

- 이 게임은 **닉네임**과 **접속 IP 주소**만 처리합니다.
- 두 정보 모두 **매치가 진행되는 동안에만** 서버 프로그램의 메모리에 있고, **파일·데이터베이스·클라우드에 저장하지 않습니다.**
- 계정, 로그인, 결제, 광고, 분석(통계) 도구, 자유 채팅이 없습니다.
- 오프라인 봇 모드는 네트워크를 사용하지 않으며 아무 정보도 전송하지 않습니다.

### 2. 처리하는 정보

| 정보 | 입력·생성 방식 | 사용 목적 | 보관 |
|---|---|---|---|
| 닉네임 | 플레이어가 직접 입력 | 로비와 매치 화면에서 플레이어를 구분해 표시 | 매치 동안 서버 메모리에만 있음. 같은 매치의 다른 플레이어에게 표시됨 |
| IP 주소 | 온라인 접속 시 네트워크 연결에서 서버가 확인 | TCP 연결 유지, 끊김 후 재접속 처리 | 연결이 유지되는 동안 서버 메모리에만 있음. 다른 플레이어에게 표시하지 않음 |

게임 규칙 진행에 필요한 이동 입력과 스킬 사용 정보도 서버로 전송되지만, 계정이나 개인과 연결되지 않으며 매치가 끝나면 사라집니다.

### 3. 처리하지 않는 정보

이름, 이메일, 전화번호, 위치 정보, 연락처, 음성·영상, 기기 고유 식별자, 결제 정보, 연령 정보를 수집하지 않습니다. 광고 식별자와 분석(통계) 도구를 사용하지 않습니다. 게임 안에서 플레이어끼리 자유롭게 글을 보내는 기능이 없습니다.

### 4. 서버와 전송

- **온라인 모드:** 게임은 TCP 연결(기본 포트 7777)로 서버에 닉네임을 보내고 매치 정보를 주고받습니다. 서버는 개발자의 개인 PC에서 실행되며 클라우드 서비스를 사용하지 않습니다.
- **직접 호스트하는 경우:** 플레이어가 자신의 PC에서 매치를 열면, 접속하는 다른 플레이어의 닉네임과 IP 주소를 그 PC가 받습니다. 게임은 이를 저장하지 않지만, 그 PC의 방화벽·공유기·운영체제가 자체 로그를 남길 수 있고 이는 게임이 통제하지 않습니다.
- **오프라인 봇 모드:** 게임 서버 로직이 앱 안에서 실행되며 외부로 데이터를 보내지 않습니다.
- 데이터는 제3자에게 판매·공유·제공하지 않습니다. 전송은 위 서버와의 연결로 한정됩니다.

### 5. 보관과 삭제

닉네임과 IP 주소는 연결이 끊기거나 매치가 끝나거나 서버 프로그램을 종료하면 메모리에서 사라집니다. 저장된 정보가 없으므로 별도 삭제 요청 대상이 되는 데이터가 없습니다.

### 6. Microsoft Store가 처리하는 정보

Microsoft Store를 통한 설치·구매 내역·평가 등은 Microsoft가 자체 개인정보 처리방침에 따라 처리합니다. 이 게임은 그 정보를 받지 않습니다.

### 7. 아동

이 게임은 계정을 만들지 않고 연령을 묻지 않으며 자유 채팅이 없습니다. 닉네임은 같은 매치의 다른 플레이어에게 보이므로, 보호자는 아동이 실명 등 개인정보를 닉네임으로 쓰지 않도록 안내해 주세요.

## English

**Game:** Ping the Killer (핑 더 킬러) — multiplayer game for Windows
**Developer:** NIPAD
**Contact:** [contact email]
**Last updated:** 2026-10-27

### 1. Summary

- The game processes only a **nickname** and the **connecting IP address**.
- Both exist only in the memory of the server program **while a match is running**. They are **not saved to files, databases or any cloud service.**
- There are no accounts, no sign-in, no purchases, no ads, no analytics and no free-text chat.
- Offline Bot mode does not use the network and sends no information.

### 2. Information processed

| Information | How it is provided | Purpose | Retention |
|---|---|---|---|
| Nickname | Typed by the player | Identify players in the lobby and the match | Held in server memory for the match only. Shown to the other players in the same match |
| IP address | Seen by the server when a player connects online | Keep the TCP connection and handle reconnecting after a drop | Held in server memory while connected only. Not shown to other players |

Movement input and skill use are also sent to the server to run the match. They are not linked to an account or a person and are discarded when the match ends.

### 3. Information not processed

The game does not collect names, email addresses, phone numbers, location, contacts, audio, video, device identifiers, payment information or age. It uses no advertising identifier and no analytics tool. Players cannot send free-text messages to each other.

### 4. Servers and transmission

- **Online modes:** The game sends the nickname to the server over a TCP connection (default port 7777) and exchanges match data. The server program runs on the developer's own PC. No cloud service is used.
- **If you host a match yourself:** The PC that hosts receives the nickname and IP address of each player who joins. The game does not store them, but that PC's firewall, router or operating system may keep its own logs, which the game does not control.
- **Offline Bot mode:** The server logic runs inside the app. No data leaves the device.
- Data is not sold, shared or given to third parties. Transmission is limited to the server connection described above.

### 5. Retention and deletion

The nickname and IP address leave memory when the connection ends, the match ends or the server program is closed. No stored data exists, so there is nothing to delete on request.

### 6. Information handled by Microsoft Store

Installs, purchases and ratings through Microsoft Store are handled by Microsoft under its own privacy statement. The game does not receive that information.

### 7. Children

The game creates no accounts, does not ask for age and has no free-text chat. A nickname is visible to the other players in the same match, so parents and guardians should tell children not to use a real name or other personal information as a nickname.

### 8. Changes to this policy

If the information processed changes, this page is updated first and the "Last updated" date is changed. Differences from the earlier text are listed at the top of the page.

### 9. Contact

Send questions about this policy to the email address above.
