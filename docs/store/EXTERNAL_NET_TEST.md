# 외부망 접속 테스트 (직접 해 주셔야 하는 단계)

목표: 다른 집이나 휴대폰 테더링 같은 **다른 인터넷**에 연결된 PC가 이 PC 서버에 접속해서 한 판을 끝까지 하는 것.
공유기 설정과 방화벽은 보안 설정이라 에이전트가 바꾸지 않습니다. 아래 단계는 직접 해 주세요.

## 1. 서버 켜기 (이 PC)

```powershell
cd C:\Unity\MultiPlayGame\PingtheKiller
dotnet run --project Server -c Release -- --port 7777 --bots 6
```

- 기본으로 모든 네트워크 주소(0.0.0.0)에서 접속을 받습니다.
- `--bots`는 0~8입니다. 사람 두 명이 테스트한다면 6으로 두면 8명이 찹니다.
- 처음 실행하면 Windows 방화벽 창이 뜹니다. **개인 네트워크**에 체크하고 허용을 누르세요.

## 2. 이 PC의 내부 IP 확인

```powershell
ipconfig
```

사용 중인 어댑터의 `IPv4 주소`(예: `192.168.0.23`)를 적어 둡니다.

## 3. 공유기 포트포워딩

1. 공유기 관리 페이지에 들어갑니다. 보통 `192.168.0.1`이나 `192.168.1.1`입니다.
2. 포트포워딩 메뉴에서 규칙을 추가합니다.
   - 프로토콜: **TCP**
   - 외부 포트: **7777**
   - 내부 IP: 2번에서 적은 주소
   - 내부 포트: **7777**
3. 같은 관리 페이지에서 **WAN(외부) IP**를 확인해 둡니다.

## 4. CGNAT 확인

웹 검색으로 "내 IP"를 찾아 나오는 주소와 3번의 WAN IP를 비교합니다.

- **같으면** 포트포워딩으로 외부 접속이 됩니다.
- **다르거나** WAN IP가 `100.64.` ~ `100.127.`로 시작하면 통신사 CGNAT입니다. 이 경우 포트포워딩으로는 외부 접속이 안 됩니다.
  대안: 통신사에 공인 IP를 요청하거나, 서버를 Oracle Cloud Always Free 서울 같은 클라우드로 옮깁니다(PLAN §1).

## 5. 바깥에서 접속

1. 다른 PC를 **다른 인터넷**에 연결합니다. 휴대폰 테더링도 됩니다.
   같은 공유기 안에서 외부 IP로 접속하면 공유기에 따라 실패할 수 있어서, 같은 집 와이파이는 테스트가 되지 않습니다.
2. 그 PC에서 게임을 켜고 Join 칸에 `<4번의 공인 IP>:7777`을 넣고 Join을 누릅니다.
3. 한 판을 끝까지 해 봅니다.

## 6. 결과 알려 주실 것

- 접속 성공 여부. 실패했다면 화면에 뜬 문구를 알려 주세요.
- 플레이 중 끊김이나 늦게 반응하는 느낌이 있었는지.
- 4번에서 CGNAT였는지.

## 참고: 출시 후 온라인 플레이

서버가 이 PC에서 돌기 때문에 PC가 꺼져 있으면 Store 사용자는 온라인 플레이를 할 수 없습니다. 오프라인 봇 모드는 항상 됩니다.
Store 설명에 접속 방법(호스트 IP 입력)과 오프라인 모드를 적어야 하고, 이 내용은 `STORE_LISTING.md`에서 다룹니다.
