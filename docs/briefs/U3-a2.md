Attempt 1 built clean and 28/28 tests passed. The orchestrator review found these issues; fix each and add or update a test proving it.

1. **H4 (gate) must not depend on H5's feature.** `AbuseAsync` currently rebinds the survivor slot via reconnect token for every mover abuse, so a server whose reconnect is broken (non-gate H5) also fails gate H4. Run the NaN, (100,100) and 500/s abuses on the existing `session.Survivor` connection. Reconnect only if the server closed that socket, and if so record it in the evidence; a server that disconnects a client for sending NaN or a flood is acceptable (that is not a crash) as long as the control Ping/Pong still works. Add a fake-server test: reconnect returns a different PlayerId → H4 still passes, H5 fails.
2. **H4 must have positive movement evidence.** The speed check is an upper bound only; if the survivor is pinned against a wall, a server that ignores clamping still passes. For the (100,100) and 500/s modes, require observed max speed ≥ 0.5 × role max (proves the mover actually moved). If the first direction yields less, retry once with the opposite direction (e.g. (-100,-100) / (-1,0)) before failing. Add a fake-server test: a server that moves the mover at 10× speed must fail H4, and a server that never moves the mover in any direction must fail H4 with "no movement evidence".
3. **H2 pass criterion must match the brief.** Attempt 1 also gates on an arrival-derived "tick-period p99 ≤ 60 ms"; that is not the server tick time and makes H2 stricter than spec (arrival p99 of 70 ms fails although the brief allows 120). Keep it as evidence only. Pass = arrival p99 ≤ 120 ms per client AND Tick strictly increasing with no gap > 2. Update README and tests.
4. **500/s flood timing must not fail on harness jitter.** `Check.Require(clock.Elapsed <= duration)` for the 500-input flood can fail on Windows timer granularity (~15.6 ms) — a harness timing slip would fail a gate against a correct server. Send larger batches (e.g. 25 batches of 20 every 40 ms), allow ≤ 1.15 s, and report the actual achieved rate in the evidence.
