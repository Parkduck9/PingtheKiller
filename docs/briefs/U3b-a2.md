The capturing contact never executes, however long the killer stays in range. The reference is `Server.Core/Runtime/GameServer.Rules.cs` lines ~70–100 in the main checkout `C:\Unity\MultiPlayGame\PingtheKiller`. It is uncommitted there; read it, never edit it.

Then walk the killer to a point > 1.5 m + margin from A (keep the existing ≥ 8 m retreat), and never let it re-enter 1.2 m of A during the rescue.
