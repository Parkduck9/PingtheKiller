## Behaviour
`dotnet run --project Tools/Harness -- --host 127.0.0.1 --port 7777 --report docs/qa/harness-latest.json [--only H1,H3]`
- Connects as real TCP clients (`TcpClient`), each with its own `PacketAssembler`.
- Runs checks H1–H6 from `docs/PLAN.md` §5, prints a table and writes JSON: `{ "total": n, "gatesPassed": bool, "items": [{ "id": "H1", "score": x, "max": 25, "gate": true, "passed": bool, "evidence": "..." }] }`. Exit code 0 only if total ≥ threshold (default 90, `--threshold`) and all gates pass.
- Assumes the server was started with `--autostart --bots N` where needed; document exactly which server flags each check expects. Where a check needs a fresh server state, it reconnects new clients rather than restarting the server.

## Checks (server behaviour per GDD / U2a brief)
- **H1 (25, gate)** framing: one client sends 10,000 valid `C2S_Ping` frames with distinct timestamps, concatenated and split into random chunks (1..1500 bytes, seeded) with random small delays; must receive 10,000 `S2C_Pong` with the same timestamps in order, zero disconnects.
- **H2 (20)** sync: 2 harness clients + server bots in a match for 60 s (`--duration` to shorten in tests); measure WorldState inter-arrival per client; pass if p99 ≤ 120 ms and `Tick` strictly increases with no gaps > 2.
- **H3 (20, gate)** masking: as the killer-bound client (start the server with the harness client as host choosing Killer via `C2S_SetRole`), observe a harness-controlled survivor that stops sending input; for ≥ 3 s collect all killer-bound frames as raw bytes; pass if the survivor's Id never appears in any PlayerState and its last known X/Z float bytes never appear in any frame. Also assert survivor-bound frames never contain the killer's Id.
- **H4 (15, gate)** abuse: separate throwaway connections send Length 0, 1, -1, int.MaxValue, 16385; unknown packet id; NaN direction; direction (100, 100); 500 MoveInputs in 1 s. Pass if the server keeps serving a control client (Ping/Pong works after each abuse) and the abusive mover's observed speed never exceeds survivor/killer max × 1.05.
- **H5 (10)** reconnect: join, note PlayerId/token, drop the socket, rejoin within 5 s with the token → same PlayerId.
- **H6 (10)** scenario: placeholder that reports `skipped (needs U2b)` with score 0 and `passed: false` — do not fake it.
