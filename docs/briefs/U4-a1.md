## Scope
1. **Shared import:** Unity imports `Shared` as a local package and compiles it. Batch import must finish with zero compile errors.
2. **Networking (`Assets/Scripts/Net/`):** `NetClient` — `TcpClient` on a background thread, `PacketAssembler` per connection, decoded packets pushed into a thread-safe queue, drained on the main thread in `Update`. Send queue off the main thread. Disconnect detection + `C2S_Ping` every 1 s, RTT shown in a debug line. Main thread never blocks on sockets.
3. **Screens (UI Toolkit or uGUI, follow SLOP_DEFINITION §8):** Main menu (Host-info line "Run the server on this PC: `dotnet run --project Server`", Join with IP:port field + validation message, Offline button visibly disabled with "Offline mode arrives in U4b"), Lobby (8 fixed slots showing player/bot/host; host-only controls: bots −/+ via `C2S_SetBots`, role choice via `C2S_SetRole`, Start). One primary action per screen. Fixed vocabulary from SLOP §8.
4. **World rendering (`Assets/Scripts/World/`):** build the map from primitives. The map data lives in `Server.Core/Runtime/Map/` (U2a) — until U2a is merged, read it from a single adapter `MapSource.cs` that U4 owns, with a hard-coded copy of the 60×60 layout described in `docs/briefs/U2a-a1.md` §2; mark it `// TODO(U4b): replace with Server.Core map`. Floor plane, wall cubes, terminals (short cylinders), exit (flat ring). Players: capsules; killer red `#E5484D`, survivors teal `#3FB8AF`, local player highlighted.
5. **Interpolation:** keep the last WorldStates; render remote entities 100 ms in the past, interpolating position and yaw; entities absent from a WorldState fade out over 150 ms (for the killer view this is the Signal→Silent disappearance).
6. **Cameras by role (from `S2C_MatchStart`):** Killer → top-down perspective camera ~35 m above the map center looking down, whole map visible. Survivor → first-person camera at eye height 1.6 m on the local player, mouse look (yaw only sent; pitch local), cursor locked during play.
7. **Input:** Input System; WASD relative to camera yaw → world-space direction (DirX, DirZ) normalized; send `C2S_MoveInput` every frame while any key is held and once with zero when released; Seq increments. (Signal is determined by the server — client just sends.)
8. **Survivor threat cue placeholder:** play a generated beep (AudioClip created in code, 880 Hz, 60 ms) at the GDD §3.2 intervals for `ThreatLevel` 1–3. No visual flash.
