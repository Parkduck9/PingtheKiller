### Wire format (from AGENTS.md)
`[int32 Length LE][ushort PacketId LE][Payload]`, `Length = 2 + payload byte count`.
- `Protocol.HeaderSize = 4`, `Protocol.IdSize = 2`, `Protocol.MaxBodyLength = 16384` (body = id + payload).
- Primitive encodings: `byte`, `ushort`, `int`, `uint`, `long`, `ulong`, `float` all little-endian. `string` = `ushort` byte length + UTF-8 bytes; every string field has a max byte length (Nickname: 48 bytes). Lists = `byte` count + items; max count is per field (PlayerState list ≤ 8, Slots = exactly 8, EscapedIds ≤ 8).
- Reading past the end, an over-limit string/list length, invalid UTF-8, or **trailing unread bytes after a packet** is a format error (`PacketFormatException`).

### Packets (`Packets/PacketId.cs` = `enum PacketId : ushort`)

| Id | Type | Fields (in wire order) |
|---|---|---|
| 0x0001 | C2S_Join | `string Nickname, ulong ReconnectToken` |
| 0x0002 | S2C_JoinResult | `int PlayerId, ulong ReconnectToken, byte Result` |
| 0x0003 | C2S_MoveInput | `float DirX, float DirZ, float Yaw, uint Seq` |
| 0x0004 | C2S_UseSkill | `byte SkillId` |
| 0x0005 | S2C_WorldState | `uint Tick, float TimeLeft, byte ExitLocked, List<PlayerState> Players` |
| 0x0006 | S2C_SkillEffect | `int CasterId, byte SkillId, float X, float Z, float Duration` |
| 0x0007 | S2C_GameResult | `byte WinnerRole, List<int> EscapedIds` |
| 0x0008 | C2S_Ping | `long Timestamp` |
| 0x0009 | S2C_Pong | `long Timestamp` |
| 0x000A | S2C_LobbyState | `Slot[8] Slots` where `Slot = {int PlayerId, string Nickname, byte IsBot, byte IsHost}` |
| 0x000B | C2S_StartMatch | (empty) |
| 0x000C | S2C_MatchStart | `byte Role, byte SkillId, int Seed` |

`PlayerState = {int Id, byte Role, byte Status, float X, float Z, float Yaw, byte Flags}`.
Also define `enum Role : byte { Survivor = 0, Killer = 1 }`, `enum PlayerStatus : byte { Normal, Frozen, Escaped }`, `[Flags] enum PlayerFlags : byte { None = 0, Signal = 1, Afterimage = 2, Stealthed = 4 }`.

Each packet is a `sealed class` with public fields, `PacketId Id`, `void Write(PacketWriter w)` and `static T Read(ref PacketReader r)`. `PacketCodec` provides:
- `byte[] Encode(IPacket packet)` → a complete frame (length + id + payload).
- `IPacket Decode(ushort packetId, ReadOnlySpan<byte> payload)` → throws `PacketFormatException` for unknown ids or format errors.

### PacketAssembler (`Net/PacketAssembler.cs`)
```csharp
public enum AssembleResult { Packet, NeedMoreData, Malformed }
public sealed class PacketAssembler {
    public PacketAssembler(int maxBodyLength = Protocol.MaxBodyLength, int initialCapacity = 4096);
    public void Append(ReadOnlySpan<byte> data);
    // payload stays valid until the next Append call
    public AssembleResult TryRead(out ushort packetId, out ReadOnlyMemory<byte> payload);
    public bool IsFaulted { get; }
}
```
- Accumulate bytes; when ≥ 4 bytes, read Length. If `Length < 2` or `Length > maxBodyLength` → `Malformed`, and the assembler becomes **permanently faulted** (every later call returns `Malformed`; `Append` is ignored).
- When `4 + Length` bytes are available, return one packet and advance; leftover bytes are kept as the start of the next message.
- Buffer reuse: advance a read offset; compact (move remaining bytes to the front) when the read offset passes half the buffer or when growth is needed. Grow by doubling, never beyond `4 + maxBodyLength` + one incoming chunk.
- No allocation per returned packet other than buffer growth.

## Acceptance tests (Server.Tests, xUnit) — all must pass

1. Round-trip every packet type with **hand-written literal values** (not values recomputed by the code), including empty lists, max-count lists, a Korean nickname (`"살인마"`), negative/large ints, `float.MaxValue`, `-0f`.
2. Golden bytes: `C2S_Ping { Timestamp = 0x0102030405060708 }` encodes to exactly `0A 00 00 00 08 00 08 07 06 05 04 03 02 01`.
3. Assembler: one whole packet; two packets in one chunk (A+B); A's head, then A's tail + B; one packet split at **every** byte offset; 1-byte drip feed of 100 packets.
4. Assembler malformed: Length = 0, 1, -1, `int.MaxValue`, `MaxBodyLength + 1` → `Malformed` and stays faulted; Length = `MaxBodyLength` exactly is accepted.
5. Decode errors: unknown packet id, truncated payload, trailing extra byte, string length over limit, list count over limit → `PacketFormatException`.
6. Fuzz (seed fixed, e.g. 12345): 10,000 random packets of random types/field values → concatenate frames → split into random chunk sizes 1..1500 → feed assembler → decode → re-encode → each frame byte-identical to the original, count identical, zero errors.
7. Architecture guard: scan `Shared/Runtime/**/*.cs` text; fail if it contains `UnityEngine`, `System.Text.Json`, `Newtonsoft`, or `System.Linq`.
