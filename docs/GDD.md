## 1. 한 줄 규칙

> **생존자는 패킷을 보내는 동안만 살인마에게 보인다.** 들키지 않고 릴레이 단말을 해킹해 탈출구를 열고, 한 명이라도 빠져나가면 생존자 승리.

## 2. 역할과 시점

| | 살인마 (1명) | 생존자 (1~7명) |
|---|---|---|
| 시점 ✅ (10/27 변경, 캐주얼한 데바데 느낌) | **1인칭** (데바데식). 마우스로 시점 회전 | **등 뒤 3인칭 + 자유 회전 카메라** (마우스로 360° 회전해 뒤를 볼 수 있음, 캐릭터는 이동 방향을 봄, 벽에 끼면 카메라가 당겨짐) |
| 보이는 것 | 1인칭 시야 + **Signal 상태 생존자는 벽 너머로도 '핑' 표식**(시야 안이면 캐릭터, 가려지면 표식) + 단말·탈출구 표식 | 3인칭 시야 + **아군 전원** + 단말·탈출구 + ✅ (10/30) **시야 안의 살인마** — 내 캐릭터 위치에서 살인마까지 벽에 가리지 않을 때만 서버가 살인마 좌표를 보냄(데바데식). 가려지면 좌표가 오지 않고, 화면에서는 마지막 위치에서 0.3 s 동안 사라짐 |
| 안 보이는 것 | 정지(Silent) 생존자 (서버가 좌표 자체를 안 보냄 — 시야 안에 있어도 안 보임) | **벽 너머의 살인마** — 3인칭 카메라로 모퉁이 너머를 봐도 내 캐릭터 위치에서 가려져 있으면 그려지지 않음 (판정 기준은 카메라가 아니라 캐릭터 위치). 탈락·탈출 후 관전 중에는 살인마가 보이지 않음 |
| 목표 | 모든 생존자 무력화 | 한 명이라도 탈출 |

## 3. 핵심 메커니즘

### 3.1 Signal / Silent (생존자 노출)
- 생존자가 **이동 입력을 보내는 동안 + 0.15 s** 🔶 → `Signal` (살인마에게 보임)
- 입력이 없으면 `Silent` → 살인마용 패킷에서 **좌표 자체를 제외** (월핵 불가)
- 단말 해킹 중에도 `Signal` (업로드 = 패킷 송신) — 목표 진행과 노출이 맞물리는 긴장 포인트

### 3.2 생존자의 살인마 감지 — "패킷 간섭" ✅(방식) 🔶(수치)
살인마가 생존자 캐릭터의 시야 밖(벽 너머)에 있으면 좌표를 **보내지 않는다** (10/30 변경: 시야 안이면 보임, §2). 서버는 거리로 **위협 단계(0~3)** 를 계산해 시야와 상관없이 항상 보낸다.

| 단계 | 살인마와 거리 | 연출 (소리 + 화면 1개) |
|---|---|---|
| 0 | 18 m 초과 | 없음 |
| 1 | 12~18 m | 느린 비프음(1.2 s 간격) + 송신 미터 가장자리에 미세한 노이즈 |
| 2 | 6~12 m | 빠른 비프음(0.6 s) + 하드디스크 긁는 듯한 잡음 |
| 3 | 6 m 이내 | 연속 비프음(0.25 s) + 화면 가장자리 정적 노이즈 |

- 방향 정보는 주지 않음 ✅ (거리만) — 숨을지 움직일지의 판단을 강요
- 서버 판정이라 클라이언트 조작으로 살인마 위치를 알아낼 수 없음

### 3.3 체포 → 패킷 손실 → 탈락 ✅
살인마에게 잡히면 얼어붙는 대신 **패킷 손실(Lagging)** 상태가 된다. 잡힌 사람도 계속 플레이하며, 아군에게 다가가 구출을 받을지 아군을 위험에 끌어들이지 않을지 판단한다.

| 항목 | 값 |
|---|---|
| 1번째 체포 ✅ | 살인마와 1.2 m 이내 → `Lagging` |
| Lagging 상태 ✅ | 이속 **25%** (1.0 m/s), **항상 Signal**(살인마에게 계속 보임), 해킹·탈출·구출·스킬 사용 불가, 화면은 프레임 끊김·잔상 연출 |
| 구출 ✅ | **모든 생존자**가 Lagging 아군과 1.5 m 이내에서 **3 s 접촉 유지** (구출 중 구출자는 Signal) / '응급 복구' 스킬 보유자는 즉시 → `Normal` |
| 타임아웃 ✅ | Lagging 후 **60 s** 안에 구출 못 받으면 **연결 끊김** → `Eliminated`(관전) |
| 2번째 체포 ✅ | 구출된 뒤 다시 잡히거나, **Lagging 중 살인마에게 닿으면** 즉시 **처형** → `Eliminated` (구출 불가) |
| 재체포 보호 | 구출 직후 2 s 무적 🔶 |
| 처형 유예 ✅ (10/27) | 잡힌 직후 **2 s 동안 처형 불가**, 그리고 처형은 살인마가 1.2 m 밖으로 **나갔다가 다시 닿아야** 성립 (잡은 순간의 접촉은 처형으로 이어지지 않음) |

### 3.4 임무 — 릴레이 단말 해킹 ✅(방식) 🔶(수치)
탈출구는 처음에 **잠겨 있다.** 생존자가 필요한 수만큼 단말을 해킹하면 열린다.

| 생존자 수 | 필요 단말 | 맵에 배치된 단말 |
|---|---|---|
| 1~2 | 2 | 4 |
| 3~5 | 3 | 5 |
| 6~7 | 4 | 6 |

- 해킹: 단말 1.5 m 이내에서 **상호작용 키 유지**, 누적 **10 s** (여럿이 함께하면 인원수만큼 빠름, 최대 3배)
- 중단해도 진행도 유지 🔶
- 해킹 중 = Signal (살인마에게 보임)
- 필요 수 달성 → 탈출구 **개방** (전원에게 알림, 살인마에게도)

### 3.5 탈출과 승패 ✅
| 조건 | 결과 |
|---|---|
| 개방된 탈출구 반경 2 m에 생존자 **1명이라도 진입** | **생존자 승리** (즉시 종료) |
| 생존자 전원이 Lagging 또는 Eliminated (정상 상태 생존자 0) | **살인마 승리** |
| 제한 시간 종료 ✅ | **살인마 승리** (제한 시간 **10분**) |

## 4. 스킬 (판마다 랜덤 1개)

### 살인마 (쿨다운 12 s 🔶)
| 스킬 | 효과 |
|---|---|
| 핑 스캐너 | 가장 가까운 생존자 1명을 1.5 s 강제 노출 |
| 오버클럭 | 3 s 동안 이속 1.5배, 이후 1 s 이동 불가 |
| 패킷 잔상 (패시브) | Signal 해제 후 1 s 더 보임 |
| 방화벽 차단 | 개방된 탈출구를 5 s 잠금 (개방 전에는 사용 불가) |

### 생존자 (쿨다운 15 s 🔶)
| 스킬 | 효과 |
|---|---|
| 더미 패킷 | 현재 위치에 3 s 가짜 Signal |
| 스텔스 중계기 | 반경 5 m 아군 2 s 동안 이동·해킹해도 Silent |
| 트래픽 과부하 | 나 2 s 강제 노출 + 살인마 이속 2 s 50% 감소 |
| 응급 복구 | Lagging 아군 즉시 구출 (접촉 시) |
| 화이트 노이즈 | 맵 곳곳에 가짜 Signal 5개, 1.5 s |

> 시너지 예: 스텔스 중계기 + 해킹 → 2 s 동안 들키지 않고 해킹. 트래픽 과부하로 살인마를 붙잡아 두는 동안 아군이 구출.

## 6. 게임 모드

### 6.1 온라인 (이 PC 서버)
- 호스트가 서버를 열고 다른 플레이어가 IP로 접속, 최대 8명. 빈자리는 봇.

### 6.2 오프라인 봇 모드 ✅
- **혼자 봇과 플레이.** 로비에서 **봇을 직접 추가·삭제** (최소 1v1, 최대 1v7)
- 역할 선택 ✅: 플레이어가 살인마/생존자를 고름 (나머지는 봇)
- 기술: 서버 게임 로직을 Unity 안에서 직접 실행 → 네트워크·외부 서버 없이 동작 (Microsoft Store 심사 대응도 겸함)

### 6.3 봇 AI 수준 🔶
- 생존자 봇: 가까운 미완료 단말로 이동 → 해킹, 위협 단계 2 이상이면 멈춰서 Silent 유지, Lagging 아군 근처면 구출 / Lagging 상태면 가장 가까운 아군 쪽으로 이동
- 살인마 봇: 마지막으로 본 Signal 위치로 추적, 없으면 단말 순찰

## 7. 한 판의 흐름

```
메인 메뉴 ─ 온라인 호스트 / 온라인 참가(IP) / 오프라인(봇)
   ▼
로비 (8칸 슬롯: 플레이어·봇, 봇 추가/삭제, 역할 선택(오프라인), 시작=호스트)
   ▼
매치 시작 (역할·스킬 발표 3 s)
   ▼
플레이 (단말 해킹 → 탈출구 개방 → 탈출 / 체포·구출)
   ▼
결과 (승리 역할, 탈출자, 해킹 수, 구출 수) → 로비
```
