S1: the hack pose was already ButtonPushing, but the U4j IK dropped the
one-hand press to the 0.72 m terminal top. That is hip height, so from
the third-person camera behind the character it read as standing idle.

- InteractionMotion / InteractionRig: an IK layer on the base pass, after
  the clip. Hack: both hands type on a chest-high floating panel on
  alternating beats. Restore: crouch and lean over the Lagging ally,
  hands down. Own exit switch hold: palm on the switch, leaning in.
  Killer model (Survivor view): one two-hand slam when a terminal next to
  it turns Regressing.
- HoloPropFx: per-character pooled props (built once): a translucent ally
  key-grid panel with a beat pulse and a packet stream from the terminal,
  an ally link line for restore, and a danger glitch burst for the jam.
  New Art/Holo/Resources URP Unlit materials.
- Masking: driven only by received flags (Hacking, Rescuing), the own
  ActionKind and the Regressing flag. The Killer view shows none.
- Locomotion: the speed blend runs at 4.0 m/s (idle / walk to 1.6 / run
  at 4.0, faster run for the Killer at 4.6 and 6.9). Rates come from the
  measured clip ground speeds, so the feet do not slide. The injured limp
  blends into the run.
